# Pasta de vídeos

Coloque aqui os arquivos de vídeo da coleção. Formatos reconhecidos: `.mp4`, `.webm`, `.mov`, `.m4v` e `.ogg`.

Para filtrar automaticamente no menu de três pontos, organize os arquivos em subpastas:

- `public/videos/vip1/`
- `public/videos/vip2/`
- `public/videos/vip3/`

O servidor lê essa pasta recursivamente em cada carregamento de `/api/videos`. Não é necessário editar o HTML para inserir novos vídeos.
